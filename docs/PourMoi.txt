TUTO — MISE EN PLACE DU CLASSEMENT EN LIGNE (Supabase)
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

ÉTAPE 1 — Créer le projet Supabase
───────────────────────────────────
1. Va sur https://supabase.com et connecte-toi (ou crée un compte gratuit)
2. Clique "New project"
3. Choisis un nom (ex: bitstream-leaderboard), un mot de passe DB, et une région
4. Attends ~1 minute que le projet démarre

ÉTAPE 2 — Créer la table
─────────────────────────
1. Dans ton projet Supabase, clique sur "SQL Editor" dans le menu gauche
2. Colle et exécute ce SQL en entier :

    create table leaderboard (
      name text primary key,
      score bigint not null default 0,
      updated_at timestamptz default now()
    );

    alter table leaderboard enable row level security;

    create policy "read"
      on leaderboard for select
      using (true);

    create policy "insert"
      on leaderboard for insert
      with check (true);

    create policy "update"
      on leaderboard for update
      using (true);

3. Clique "Run" — tu dois voir "Success. No rows returned."

ÉTAPE 3 — Récupérer les clés API
──────────────────────────────────
1. Dans le menu gauche, clique "Project Settings" (icône engrenage)
2. Clique "API"
3. Copie :
   - "Project URL"      → c'est ton VITE_SUPABASE_URL
   - "anon public" key  → c'est ton VITE_SUPABASE_ANON_KEY

ÉTAPE 4 — Configurer le projet local
──────────────────────────────────────
Ouvre le fichier .env.local à la racine du projet et remplis :

    VITE_SUPABASE_URL=https://xxxxxxxxxxxxxx.supabase.co
    VITE_SUPABASE_ANON_KEY=eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9...

ÉTAPE 5 — Relancer le serveur
──────────────────────────────
    npm run dev

Le classement affichera "🌐 En ligne" au lieu de "🤖 Local (bots)".
Ton score est envoyé automatiquement toutes les 5 minutes.
